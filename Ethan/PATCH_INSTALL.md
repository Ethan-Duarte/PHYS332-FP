# Updating an existing N-Baddies V1.5.1 project

Extract the contents of the patch ZIP **directly into your existing project root** (the folder containing `app.py`, `nbody/`, `scripts/` and `start_gui.bat`). Allow files to be replaced when prompted. Do not put an extra `nbody_v1_5` folder inside it. The update does not modify your existing `results/runs/` or `results/galaxies/`.

Alternatively, use the complete V1.6 zip and copy your `results/runs/` and `results/galaxies/` from your old project to the new one.

Run `start_gui.bat` on Windows or `bash start_gui.sh` on macOS, and open the **Virialize & relax galaxies** tab. AGAMA installation instructions: `docs/WINDOWS_AGAMA_POWERSHELL.md`.
