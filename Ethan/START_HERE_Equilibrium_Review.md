# Equilibrium diagnostic patch

Extract these files INTO the existing PHYS332-FP/Ethan folder. They add new
helpers and results; the original GUI adapter and cached galaxies are untouched.
Use your existing working .venv (AGAMA, NumPy and Numba already installed).
No pip upgrade or data download is needed.

Start with docs/instability_review/RESULTS.md. Important: the corrected low-N
live galaxy STILL thickens. This is experimental diagnostic code and prebuilt
candidates, not a stability-certified release or a finished Mice encounter.

## Recommended next test: timestep refinement of the higher-halo control

In PowerShell, from Ethan:

```powershell
.\.venv\Scripts\python.exe .\agama_softened_control.py --screen .\results\softened_review\halo_24000\candidate.npz --threads 4 --steps 256 --dt 0.00048828125
```

This keeps t=0.125 and halves dt relative to the reproduced 128-step test.
The baseline comparison is in docs/instability_review/reproduced_runs/halo_4x/.
The runner prints a measured force-time forecast and saves checkpoints.
Send the new screen folder's summary.json and live_metrics.json.
The script intentionally gives no automatic scientific validation verdict.

## Repeat a seed without rerunning the SCM loop

```powershell
.\.venv\Scripts\python.exe .\resample_softened_candidate.py .\results\softened_review\halo_24000\candidate.npz --seed 43 --steps 128 --threads 4
```

Unspecified component counts are inherited. Changing the seed resamples all
components from the same underlying DF; unchanged seed and counts copy the
original particle arrays exactly. Configuration and provenance remain in NPZ.

This is a longer test. Check its measured forecast before committing; Ctrl+C

## Construct a new softening-compatible candidate

```powershell
.\.venv\Scripts\python.exe .\agama_softened_control.py --interpolated-actions --threads 4 --epsilon 0.00625 --build-only
```

The faster SCM action approximation has a fresh non-interpolated density check.
Omitting --interpolated-actions uses a much slower construction. Every candidate
must pass the numerical construction checks before a particle snapshot is saved.
Those checks do not certify live stability. Changing epsilon requires building
new initial conditions; the test runner rejects an epsilon mismatch.

## Diagnostic static-spheroid control

```powershell

```

This removes spheroid noise AND response. It is not the production merger model.
